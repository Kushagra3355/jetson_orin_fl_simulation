  This happens because the data generator uses a fixed random seed configured for each node.

  Here is the step-by-step reason why only timestamps change upon restarting:
  ──────
  ### 1. Fixed Random Seed in Node Configs

  In your node configuration files (such as jetson01.json), the seed parameter is set to a static integer value (e.g. "seed": 101):

    {
      "client_id": "jetson01",
      "patient_profile": "obstructive_pattern",
      "seed": 101,
      ...
    }
    ──────
  ### 2. Deterministic Pseudo-Random Generator

  When patient_node.py in patient_node.py runs on node startup, it passes this fixed seed to bipap_simulator.py:

    # In edge/bipap_simulator.py
    rng = np.random.default_rng(seed)
    
  Because seed=101 is fixed, NumPy's random number generator produces the exact same sequence of numbers for features like
  respiratory_rate, tidal_volume_ml, leak_lpm, spo2_percent, and synthetic_target_adjustment_cmh2o every time the node starts up.
  ──────
  ### 3. Dynamic Timestamps

  The only dynamic field is timestamp_utc, which uses the current system clock at runtime:

    start = datetime.now(timezone.utc).replace(microsecond=0)
    "timestamp_utc": (start + timedelta(seconds=index * 2)).isoformat()
    
  As a result, each restart records the current clock time, but all synthetic health metric values remain identical.
  ──────
  ### How to Generate New Data on Every Restart

  If you want different random data generated every time you start/restart a node, you can update the seed dynamically.

  #### Option A: Change "seed" in the JSON config

  Edit jetson01.json to use a different integer (e.g. "seed": 999).

  #### Option B: Use System Clock Seed in Code

  In patient_node.py, you can fallback to the current timestamp as seed if desired:

    import time

    seed_val = settings.get("seed") or int(time.time())
    rows = generate_records(
        client_id=settings["client_id"],
        profile_name=settings["patient_profile"],
        samples=int(settings.get("samples", 480)),
        seed=seed_val,
    )
